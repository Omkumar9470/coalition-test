A professional, custom-coded WordPress theme implementation based on PSD design requirements. This project showcases the ability to translate static design files into a fully functional, dynamic, and responsive WordPress environment.

## 🚀 Features

- **Custom Theme Development:** Built from scratch (`ct-custom`) to ensure full control over site architecture.
- **PSD to Web Fidelity:** Pixel-perfect layout implementation matching the provided design specs.
- **Dynamic CMS Integration:**
    - Custom Header/Footer implementation.
    - WordPress Menu integration (`wp_nav_menu`).
    - Dynamic content rendering via `get_option` for site configuration.
- **Interactive Forms:** Integrated Contact Form 7 with custom CSS styling to match the brand identity.
- **Fully Responsive:** Optimized layouts for varying screen sizes, ensuring a seamless user experience.

## 🛠 Tech Stack

- **Platform:** WordPress 7.x
- **Languages:** PHP, HTML5, CSS3
- **Tools:** Contact Form 7, LocalWP, Custom CSS/PHP
